更新マニュアル

店舗責任者・オーナー向けのかんたん更新手順です。基本は設定画面から操作します。

1. お知らせを追加する

  1. 設定画面を開く
  2. 「お知らせを編集する」を押す
  3. 「1行追加する」を押す
  4. 日付をカレンダーで選ぶ
  5. 表示を「表示する」にする
  6. 本文を入力する
  7. 「保存用ファイルを作る」を押して、news.json を上書きする

2. スプレッドシートでお知らせを更新する

  1. Googleスプレッドシートを開く
  2. date、title、visible の3列を使う
  3. 表示したいお知らせは TRUE、隠したいお知らせは FALSE にする
  4. シートを「ウェブに公開」し、CSV URLを news-config.js に入れる

3. LINE・Instagram・電話番号を変える

  1. 設定画面を開く
  2. 「リンクを変更する」を押す
  3. 新しいURLや電話番号を入力する
  4. 「設定ファイルを作る」を押して、site-config.js を上書きする

4. 写真を変える

  1. 設定画面を開く
  2. 「写真を変更する」を押す
  3. 変えたい写真を選ぶ
  4. 新しい写真を選ぶ
  5. 「この名前で保存」を押して、同じフォルダに上書きする

5. プライバシーポリシーを確認する

  1. LINE予約で取得する氏名・電話番号・相談内容などの扱いを確認する
  2. 変更が必要な場合は、制作側へ修正文を共有する
プライバシーポリシーを見る

6. 口コミ・系列店実績を確認する

  1. 系列店「Salon de CERM」の実績・口コミを確認する
  2. Googleビジネスプロフィールができたら、地図・口コミ導線を店舗用URLへ差し替える
